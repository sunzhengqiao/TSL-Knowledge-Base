# hsbTileLath

## Overview

The **hsbTileLath** script creates the distribution of tile laths (battens) that support roof tiles. It generates both standard laths following the roof tile distribution and special laths at eaves (edges) of the roof. The script reads roof tile data from roof planes and calculates lath positions based on tile geometry.

This tool is essential for creating the structural support system for roof tiles, ensuring proper alignment and spacing for tile installation.

## Prerequisites

Before using this script, ensure:

1. **Roof Planes are Configured:** The selected roof planes must contain `Hsb_TileExportData` and `Hsb_RoofEdgeTileData` submaps, typically generated by a roof tile configuration script
2. **Tile Definitions Exist:** Eave and ridge tile definitions must be specified on the roof plane to determine lath dimensions
3. **Extrusion Profiles:** Valid extrusion profiles must exist in the catalog for optional eave profile override
4. **hsbTileHipRidge (Optional):** For proper hip and ridge batten positioning, the `hsbTileHipRidge` script should be attached to the roof plane first

## Usage

### Standard Lath Generation

1. Launch the script via `TSLINSERT` command or from the hsbCAD Catalog
2. A dialog appears for parameter configuration (or use a catalog preset)
3. Select one or more roof planes when prompted: "Select roofplane(s)"
4. The script automatically generates:
   - **Standard tile battens** at the vertical distribution points defined in the tile data
   - **Eave battens** at the eave edge with optional extrusion profile override
   - **Hip battens** along hip edges (if `hsbTileHipRidge` data exists)
   - **Ridge battens** along ridge edges (if `hsbTileHipRidge` data exists)

### Erase Lath Mode

Use the command key `ERASELATH` to remove existing laths:

1. Execute with the ERASELATH key
2. Select the roof plane(s)
3. Select specific laths to erase, or press Enter to erase all associated laths

### Split Lath Mode

Use the command key `SPLITLATH` to split existing laths at specific locations:

1. Execute with the SPLITLATH key
2. Select the roof plane(s)
3. Select the laths to be split
4. Pick splitting point(s)
5. Press Enter to complete

## Technical Details

### Lath Types and Colors

| Lath Type | Color Code | Description |
|-----------|------------|-------------|
| Standard Lath | 35 | Regular horizontal tile battens |
| Ridge Lath | 145 | Battens at roof ridge |
| Hip Lath | 225 | Battens along hip edges |

### Lath Dimensions

- Lath width and height are automatically determined from the ridge tile definition stored in the roof plane (`LathWidth`, `LathHeight`)
- If no valid lath dimensions are found, the script displays a warning: "Could not detect the section of the laths. Did you specify the eave and ridge tile?"

### Beam Properties

All generated battens are:
- Set to beam type: `_kLath`
- Tagged with the roof plane handle in `subLabel2` for easy identification and erasure
- Named appropriately: "Ridge Lath" or "Hip Lath" for special battens

### Configuration Source

This script reads configuration directly from the selected Roofplane's submaps:
- `Hsb_TileExportData` - Contains vertical distribution points and tile plane data
- `Hsb_RoofEdgeTileData` - Contains edge-specific tile definitions (eave, ridge, hip)
- `Hsb_RoofTile` - Contains roof family definition

## Tips

1. **Check Tile Definitions First:** Ensure the roof plane has valid eave and ridge tile definitions before running this script. Missing definitions will prevent lath dimension detection.

2. **Use with hsbTileHipRidge:** For complete hip and ridge batten placement, run `hsbTileHipRidge` on the roof plane before generating laths. The positioning height of edge laths is taken from the hsbTileHipRidge instance.

3. **Custom Eave Profiles:** For specialty eave battens (e.g., ventilation battens, tilting battens), use the Extrusion Profile Override parameter to select a custom cross-section profile.

4. **Catalog Presets:** Save frequently used configurations as catalog entries for quick application via the execute key.

5. **Static Geometry:** Note that generated laths do not automatically update when the roof plane changes. Re-run the script after modifying the roof geometry.

6. **Split for Joints:** Use SPLITLATH mode to create material joints at specific locations, such as at panel boundaries or structural connections.

7. **Avoiding Duplicates:** When re-generating laths, use ERASELATH mode first to remove old laths before creating new ones.

8. **Shed Roofs:** The script automatically detects shed roofs and will not create ridge battens (as per version 1.6 logic).

## FAQ

**Q: I get the error "hsbTileLath: invalid selection set." What is wrong?**
A: The Roofplane you selected is missing the necessary data. Ensure the Roofplane has been processed by a tile configuration tool to generate the `Hsb_TileExportData`.

**Q: The laths are not aligning with my tiles.**
A: Check the **X-Offset** in the properties. Also, verify that the `VerticalDistribution` points in the roofplane data match your tile dimensions.

**Q: Why is there no ridge batten on my roof?**
A: The roof is likely identified as a "Shed Roof" (single slope). The script suppresses ridge battens for this roof type.

**Q: Can I change the profile of just the bottom row (eave)?**
A: Yes. Use the **Extrusion Profile Override** property to select a specific profile for the eave row. The rest will use the standard rectangular profile defined in the tile data.

**Q: My hip/ridge laths are at the wrong height.**
A: Ensure an `hsbTileHipRidge` instance is attached to the roofplane to provide the correct elevation data.
